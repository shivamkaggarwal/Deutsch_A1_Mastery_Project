# Deutsch A1 Mastery — Grammar & Vocabulary Lab

**Learn. Practise. Transform. Master German A1.**

A self-contained, responsive German A1 revision app built from the supplied grammar syllabus and its 295-entry course vocabulary list. It uses plain HTML, CSS and JavaScript, so there is no build step, account, paid API, or backend requirement.

## Open the app

**Fastest:** open `index.html` in a recent desktop browser (Chrome or Edge recommended). Keep `styles.css`, `vocabulary.js`, and `app.js` next to it in the same folder.

**Single file:** use `Deutsch_A1_Mastery_Standalone.html` outside the project ZIP if you prefer one HTML file with the styles and scripts embedded.

## Included

- Dashboard with live local progress, daily target, study path, streak and recent activity.
- 12 grammar learning modules: Aussagesatz, W-Frage, Satzfrage, Imperativ, separable verbs, modal verbs, personal pronouns, possessive determiners, Nominativ, Akkusativ, Dativ and ordinal numbers.
- Full course vocabulary list: all 295 numbered entries, including examples and English translations, searchable with category and word-type filters.
- Vocabulary quiz modes for German → English, English → German, article selection, plurals, sentence context and fill-the-gap practice.
- Sentence transformation lab, flashcards, random practice, daily challenge, quick-reference sheets and a mistake notebook.
- 570-question practice pool (275 grammar questions plus a vocabulary meaning item for every supplied vocabulary entry).
- Two 30-question custom classroom mock-test versions with optional timer, navigation, score and topic feedback. This is not an official Goethe-Institut test.
- Light/dark theme, responsive layout and browser-local progress tracking.

## Progress and privacy

Progress and theme preferences are stored in local browser storage. That means progress belongs to the browser/device in which you use the app. There is no account sync or backend. Browser behaviour when opening local files directly can vary; publishing the project to a static host is preferable for consistent storage and sharing.

## Publish a shareable URL

The app has **not** been deployed publicly by this package. To publish it:

1. Extract this project ZIP.
2. Upload the project folder (or its five runtime files: `index.html`, `styles.css`, `vocabulary.js`, `app.js`, `README.md`) to a static hosting service such as Netlify, or push the files to a GitHub repository and enable GitHub Pages.
3. Make sure `index.html` is the published site root. No npm install or build command is required.
4. Open the hosting URL in a private/incognito browser and test a lesson, quiz, theme toggle and mock exam before sharing it with classmates.

## Files
